# Daily Record Android

Aplikasi Android WebView untuk:
https://sites.google.com/view/dayli-report/home

Nama aplikasi: Daily Record
Application ID: com.dailyrecord.app

## Build APK
1. Buka project ini di Android Studio.
2. Tunggu Gradle Sync selesai.
3. Pilih Build > Build APK(s).
4. APK debug biasanya berada di app/build/outputs/apk/debug/app-debug.apk.

Project juga sudah memakai GitHub Actions. Jika project diunggah ke GitHub, workflow akan membangun APK secara otomatis.
